# 🃏 Memory Match Game

A responsive and interactive Memory Match Game built with React, Vite, and Tailwind CSS.

## ✨ Features

- 🃏 Card-flipping animation
- 🎯 Matching-pair game logic
- 🔢 Move counter
- ⏱️ Game timer
- 🏆 Best score tracking
- 💾 Scores saved with localStorage
- 🔄 Restart functionality
- 🎚️ Four difficulty levels
- 📱 Responsive design
- 🎉 Win notification

## 🎮 Difficulty Levels

| Level | Pairs | Cards |
|---|---:|---:|
| Easy | 4 | 8 |
| Medium | 6 | 12 |
| Hard | 8 | 16 |
| Expert | 10 | 20 |

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
